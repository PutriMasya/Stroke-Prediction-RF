# Stroke-Prediction-RF

### Stroke Prediction using Random Forest
Proyek ini bertujuan untuk memprediksi risiko stroke berdasarkan faktor kesehatan pasien menggunakan model Random Forest. Dataset yang digunakan berasal dari Healthcare Dataset Stroke Data.

### Dataset
Sumber: Healthcare-Dataset-Stroke-Data
Jumlah data: 5,110 baris
Fitur utama: age, hypertension, heart_disease, avg_glucose_level, bmi, smoking_status, dll.
Label target: stroke (0 = Tidak, 1 = Ya)

### Teknik yang Digunakan
Data Preprocessing:
## ✅ Mengatasi Missing Value dengan imputasi mean
✅ Mengatasi Outlier
✅ Normalisasi semua fitur numerik
✅ Mengatasi ketidakseimbangan kelas dengan SMOTE
✅ Encoding fitur kategori

### Model Machine Learning:
✅ Random Forest sebagai model utama
✅ Evaluasi: Akurasi, Precision, Recall, F1-score, Confusion Matrix
